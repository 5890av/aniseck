# Aniseck

Build a clean, modern AniList client web app using React. Use the public AniList GraphQL API (https://graphql.anilist.co) so no API key is needed for searching. Include: 1) A home page showing currently trending and popular anime with cover images, ratings, and episode counts. 2) A search bar to find any anime or manga. 3) A details page when clicking an anime showing its synopsis, genres, trailer, and characters. 4) A local 'My Watchlist' tab where I can save shows as Watching, Completed, or Plan to Watch."
